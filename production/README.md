# Production files

Manufacturing outputs, ready to send off / print / flash.

| File                       | What it is                                          |
|----------------------------|-----------------------------------------------------|
| `gerbers.zip`              | Gerbers + drill file for the PCB (KiCad, 2-layer)   |
| `focus-totem-plate.stl`    | Top switch plate — print flat, face-up, no supports |
| `focus-totem-bottom.stl`   | Bottom tray — print flat, floor-down, no supports   |
| `firmware.uf2`             | Compiled QMK firmware (RP2040)                       |
| `focus-totem.scad`         | OpenSCAD source the two STLs and the CAD model come from |
